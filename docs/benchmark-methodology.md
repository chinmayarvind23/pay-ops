# Benchmark Methodology

The implemented release evaluations and remaining study designs are distinct:

```text
24 reproducible failure scenarios
120 unauthorized remediation attempts
paired investigation baseline
root-cause ranking
evidence attribution
execution-path grading
model-step latency
LLM cost
```

Qualification receipts retain source/image identity, activation, observations and
cleanup. Separate model replay runs retain frozen prompts, model receipts, outputs,
usage, scoring inputs and failures. A scenario qualification is not a complete model
investigation. See [model results](model-replay-results.md) and the
[source-bound attribution review](attribution-review.md) for their exact scopes.

Investigation duration:

`accepted_report_time - incident_accepted_time`

Agent-step latency:

`validated_model_output_time - model_request_time`

The proposed manual baseline would use the same scenarios and documented read-only
observability/runbook tools, without PayOps recommendations. No paired human study
has been performed; the original 11.8-to-2.9-minute claim remains unsupported.

Do not discard timeouts, security blocks, missing-evidence cases, action failures, or structured-output failures.

Headline `$0.07` refers to LLM provider cost unless explicitly broadened.

The original planned combined-study layout below is not the format generated by the
completed replay runner. Actual reproducible results are JSON under `evals/results`,
with source excerpts under `evals/replay-v1` and private runtime receipts under
`resources/pay_ops/evidence`. Parquet and a combined human/model study remain extensions.

```text
benchmarks/results/<run_id>/
  manifest.json
  scenario_results.parquet
  evidence_attributions.parquet
  execution_path.jsonl
  unauthorized_actions.jsonl
  model_steps.parquet
  cost.json
  summary.json
  notes.md
```
