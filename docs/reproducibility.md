# Reproducibility

Record git SHA, scenario/version hash, image digests, GKE/Kubernetes version, Terraform revision, deployment SHAs, model/provider version, prompt/tool versions, Elasticsearch index version, runbook corpus hash, traffic seed, fault parameters, timestamps, and region/cluster.

A scenario is complete only after cleanup verifies the declared healthy baseline.

Preserve references/hashes to raw logs, traces, metrics, events, and deployment data, not only model summaries.

Public sanitization creates a new artifact version/hash.
